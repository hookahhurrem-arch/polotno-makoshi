Полотно Макоши — загрузка на Amvera
===================================

1. На шаге «Загрузка данных» нажмите «Загрузить только файла»
   и выберите этот архив polotno-makoshi-amvera.zip
   (лучше с компьютера, не с телефона).

2. Commit message можно оставить как есть. Далее.

3. Если спросит язык — Node.js, не Python.

4. После сборки сайт откроется на адресе вида
   https://temnoiar-имя.amvera.io

5. Свой домен temnoiar.ru:
   в Amvera → Домены → добавить temnoiar.ru
   в Рег.ру в DNS поставьте те записи, которые покажет Amvera.
   Старый A-адрес 37.140.192.114 для сайта уберите.

6. Ткач (умные расклады) на Amvera не заговорит сам.
   В настройках проекта → переменные окружения добавьте:
   XAI_API_KEY = ключ с https://console.x.ai
   Ключ в чат не присылайте.

Не загружайте: сертификаты SSL, ключи, папку node_modules.
